新手做美宣插画最常踩的坑：比例、透视、光影等 7 大问题
美宣插画不是“画得细”就行，它要在一张图里完成角色展示、氛围营造和商业信息传递。新手最容易在基础关系上翻车：比例不对、透视散了、光影不统一，细节再多也救不回来。下面七个坑最典型，越早改越省时间。

问题一：比例失调，角色站不住。 常见表现是头大身短、手臂过长、肩膀和胯部不在一个体块逻辑里，或者武器比人还重却拿得很轻松。破解方法是先画火柴人和体块，再画剪影，最后才抠五官和衣服。美宣插画常有夸张透视，但夸张不等于没有结构。把角色缩到很小看外轮廓，如果剪影读不出职业和姿态，比例一定有问题。多人画面还要检查角色之间的身高、头身比和远近关系，不能各画各的。

问题二：透视混乱，空间像贴纸。 新手常把角色、道具和背景分别画好再拼在一起，结果地平线不一致、视平线乱跳、地面没有纵深。破解方法是先定镜头：视平线高度、焦距感、消失点方向，再让角色、道具和场景共用同一套透视。近景大、远景小，但缩变要符合空间，不是随意缩放。地面接触点要清楚，脚底、阴影和反射要落在同一平面上。检查方法：画几条透视线穿过画面，看主要结构是否朝同一方向收束。

问题三：光影逻辑乱，画面没有体积。 常见问题是主光方向不明确，左边亮右边也亮，阴影色直接加黑，高光到处乱点。美宣插画需要明确的光影叙事：主光定情绪，补光提暗部，边缘光分离主体。先定一个主光源，再决定明暗交界线和投影方向。阴影不要只用固有色压暗，要带环境色和冷暖偏移。金属、皮肤、布料的高光形状要区分，不能全用同一种圆亮点。眯眼看画面，主体是否突出、暗部是否透气，一眼就能判断。

问题四：构图没有焦点，观众不知道看哪。 新手容易把角色放正中，背景塞满元素，结果第一眼找不到重点。美宣插画要有视觉引导：用线条、光影、色彩对比和留白把视线推向脸、武器或核心道具。主体不一定居中，但要有明确的主次。前景、中景、背景要分层，背景不能抢角色。出图前问自己：第一眼看哪里？第二眼看哪里？如果答案是“到处都看”，构图就失败了。裁切和镜头高度也要服务内容，不要默认平视全身。

问题五：色彩脏灰，冷暖关系不清。 颜色发灰通常不是饱和度不够，而是明度关系混乱、环境色污染固有色、阴影色乱调。破解方法是先做黑白灰草图，确认明暗层次，再上固有色。定主色、辅色和点缀色的比例，高饱和放在焦点，背景降饱和。阴影色要偏冷或偏暖，但不能只加黑。皮肤、布料和金属的冷暖倾向要统一在环境光里。去色检查：如果黑白关系清楚，彩色才站得住。

问题六：材质平均，细节没有主次。 新手常把头发、衣服、武器、背景都画到同样精细，结果画面很累却没有重点。美宣插画要控制细节密度：脸和核心道具高精度，身体和背景适当简化。材质要讲逻辑：布料有褶皱和厚度，金属有硬边高光和反射，皮肤有次表面透感。磨损、污渍和边缘变化要服务设定，不是随便加噪点。细节放在视觉焦点，其他区域学会省略。

问题七：叙事弱，角色像摆拍。 美宣插画不是立绘展示，要有情境：角色在做什么、面对什么、情绪是什么。新手常让角色站着看镜头，姿势没有动势，道具和背景各说各话。破解方法是先写一句画面故事，再定动作、表情和构图。姿态要有重心和动势线，手部动作要参与叙事，背景元素要呼应角色身份。商业信息如品牌元素、文字留白和产品展示，也要在构图阶段预留，不能最后硬塞。

美宣插画的完成度，来自比例、透视、光影、构图、色彩、材质和叙事的共同成立。建议每次出图前固定检查这七项，先保证第一眼可读，再追求细节和风格。基础关系稳了，画面才有商业说服力。
